- [ ] Reverse Linked List (Easy) — Blind 75 / NeetCode 150

- [ ] Remove Duplicates from Sorted List (Easy) — NeetCode 150

**Patterns learned:** traversal, `head`, `next`, pointer reassignment, dummy nodes, sequential processing.
